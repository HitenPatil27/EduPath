# Project Report: EduPath AI Career Intelligence

## 1. Executive Summary
**EduPath AI** is a cutting-edge career recommendation platform designed to guide students and professionals toward their ideal career paths using Artificial Intelligence. Unlike traditional static quizzes, EduPath leverages an adaptive, AI-driven questionnaire that evolves based on user input, culminating in a data-rich "Career Blueprint" featuring top 10 matches, skill gap analysis, and market insights.

## 4. Feature Set & Implementation

### 4.1 Onboarding Wizard
The onboarding flow is a 3-step dynamic wizard that collects:
1.  **Education Background**: Level, Field of Study, Institution, and Graduation Year.
2.  **Interests & Hobbies**: A multi-select interactive grid to establish the user's "Core Interests."
3.  **Review**: A glassmorphic summary for user verification before initiating the AI session.

### 4.2 Adaptive AI Questionnaire
Managed by the `AIAgentService` logic in `app.py`:
- **Adaptive Questions**: The AI (GPT-OSS 120B) generates questions one by one.
- **Context Awareness**: Each question is based on the user's profile and previous answers.
- **Termination Logic**: The AI determines when it has enough information (typically 6-10 questions) to finalize the report.

### 4.3 Career Results & Ranking Engine
Once the questionnaire is complete, the AI performs a secondary "Analysis Phase":
- **Ranking**: Generates a ranked list of 10 careers.
- **Details**: Provides "Why It Fits You," "Skill Requirements," "Salary Ranges," and "Growth Outlook."
- **Visuals**: Results are displayed using animated progress rings and premium glass-cards.

### 4.4 User Dashboard (My Pathways)
A persistent history page where users can:
- View all past assessment sessions.
- Continue "In Progress" sessions.
- Revisit and print/download completed Career Blueprints.

## 5. System Architecture

### **Database Schema**
- `User`: Profile data, authentication hashes, and completion status.
- `UserInterests/Hobbies`: Relationship-mapped attributes.
- `Session`: Tracks individual assessment attempts (In-progress/Completed).
- `QAHistory`: Stores every question asked and answered for LLM context injection.
- `Recommendation`: Persistent storage of the final top 10 career matches.

### **API Endpoints**
- `POST /api/auth/register` & `POST /api/auth/login`: Identity management.
- `PUT /api/profile`: Updates user attributes.
- `POST /api/session/start`: Initializes a new AI assessment.
- `POST /api/session/answer`: Processes a response and triggers the next adaptive question.
- `POST /api/session/finish`: Transitions the session to the analysis and ranking phase.
